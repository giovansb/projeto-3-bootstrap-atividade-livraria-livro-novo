# Livraria Livro Novo - Site com Bootstrap

Projeto de um site de livraria desenvolvido para praticar a criação de layouts responsivos utilizando Bootstrap.

## 🚀 Tecnologias
- HTML
- CSS
- Bootstrap

## 📚 Sobre o projeto
O site simula a interface de uma livraria online, com foco na apresentação de livros e organização de conteúdo.

## ✨ Funcionalidades
- Layout responsivo com grid
- Carousel de imagens para destaque
- Navegação entre seções
- Estrutura organizada com componentes do Bootstrap

## 📖 Seções do site
- Sobre a livraria
- Destaques
- Nosso acervo
- Fale conosco

## 🔗 Acesso ao projeto
https://livraria-livro-novo.vercel.app/

## 💻 Como rodar o projeto
1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
